## 1. Terminology Learned

| Term | Simple definition | Status |
|---|---|---|
| Target | Protein (often a kinase) driving disease; has a pocket ligands bind | covered |
| Ligand | Small molecule that binds the target's pocket | covered |
| Binding affinity | Strength of ligand-target binding; Kd = [T][L]/[TL] | covered |
| Ki | Inhibition constant from a competition binding assay | covered |
| IC50 | Conc. needed for 50% inhibition in a functional assay; assay-dependent | covered |
| pIC50 | -log10(IC50 in M); used as ML regression target | covered |
| Assay | Standardized lab test/protocol producing the measurement (e.g., IC50) | covered |
| Kinase | Enzyme that phosphorylates proteins to relay signals; common cancer target class | covered |
| QSAR | Structure → model → predicted activity (e.g. pIC50); similarity principle | covered |
| Molecular fingerprint | Fixed bit vector encoding substructures (Morgan/ECFP: hashed neighborhoods per atom/radius) | covered |
| SMILES | Text encoding of molecular structure; not unique, canonicalize before dedup/split | covered |
| Molecular descriptor | Interpretable numeric property (MW, LogP, HBD, HBA, TPSA); basis of Lipinski Ro5 | covered |
| ADMET | Absorption/Distribution/Metabolism/Excretion/Toxicity — whether a binder can actually be a drug | covered |
| Docking | Predict ligand pose/score in a target's 3D pocket; scores correlate poorly w/ true affinity (known limitation) | covered |
| Virtual screening | Computationally rank a huge compound library (SBVS=docking, LBVS=similarity/QSAR) before wet-lab testing | covered |
| Molecular dynamics | Simulate atom motion of complex over time via force field; refines/validates top docking hits, expensive | covered |
| Bioactivity databases | ChEMBL (curated lit), BindingDB (affinities+structures), PubChem (large/noisy HTS), Davis & KIBA (kinase DTA benchmarks), PDBbind (structure+affinity), TDC (ML-ready, standardized splits) | covered |
| DTI vs DTA | DTI = binary interaction; DTA = regression on affinity (pKd/pIC50) — your work is DTA | covered |

## 7a. Major Finding: EGFR ChEMBL Data is Dominated by Compound Mutations (this session)

**Resolves the long-standing "unresolved: verify whether ChEMBL's assay_variant_mutation field encodes compound mutations" question, and it's bigger than expected.** Direct query of all EGFR (CHEMBL203) variant-annotated activity records shows the field does encode compound mutations, comma-separated, and they dominate the T790M/C797S-relevant data:

| assay_variant_mutation value | n records |
|---|---|
| L858R,T790M | 3,402 |
| UNDEFINED MUTATION | 2,135 |
| L858R | 2,109 |
| T790M | 1,361 |
| L861Q | 1,071 |
| L858R,T790M,C797S | 971 |
| G719C | 249 |
| G719S | 239 |
| C797S,L858R | 79 |
| C797S | 33 |
| T790M,L858M | 30 |
| T790M,C797S | 30 |

**Implication for the study design:** the original plan (score T790M and C797S independently against WT) doesn't match the real data — C797S essentially never occurs without T790M already present (only 33 pure-C797S records vs. 971 for the L858R+T790M+C797S triple mutant), because C797S is specifically third-generation-inhibitor resistance that arises on top of existing first-gen-TKI resistance (T790M), which itself arises on top of the original driver mutation (L858R). **Redesigned matched-pair comparisons, using the actual data-populated cascade:**
1. WT vs. L858R (driver mutation effect)
2. L858R vs. L858R+T790M (acquired first-gen-TKI resistance — 3,402 candidate matched pairs, not 1,361)
3. L858R+T790M vs. L858R+T790M+C797S (acquired osimertinib resistance — 971 candidate matched pairs)

This requires re-scoring T790M against an L858R background (not WT) and C797S against an L858R+T790M background (not just T790M background as originally built) — background-aware scoring turns out to be the dominant real-world case, not a special-case nicety. ABL1 checked for the same pattern before finalizing the pulling/scoring code for both kinases together (see next entry once checked).

## 7b. EGFR + ABL1 Cross-Kinase Extension — Complete First Pass (this session)

**Pipeline built and fully run on Kaggle** (`egfr_abl1` notebook, built cell-by-cell with live debugging). Summary of what it does and what it found:

**Real bugs caught and fixed along the way (all documented live, not glossed over):**
1. ESM-1b has a hard 1024-token architectural cap (learned positional embeddings) — full-length EGFR (1210aa) and ABL1 (1130aa) both exceeded it. Fixed by fetching each kinase's UniProt-annotated kinase domain (EGFR 712-979, ABL1 242-493, both independently confirmed matching earlier session estimates) plus 150 residues of flanking context, applied identically across all four models to keep the comparison fair.
2. GPU OOM on ESM-2-3B after the other three models had already loaded — root cause was `del model; torch.cuda.empty_cache()` without `gc.collect()` first, so Python wasn't actually releasing the deleted models before the cache check. Fixed by adding explicit `gc.collect()` after every model, not just the failing one.
3. ChEMBL API rejected `assay_variant_mutation__icontains` (HTTP 400) — the field only allows `exact/iexact/isnull/in` lookups per its own schema (checked directly rather than guessing a second time). Fixed by pulling non-null-variant records and filtering client-side, later switched to `exact` once the real distinct values were known.
4. A pandas merge bug inflated "matched pairs" by up to ~20x (M244V went from 6 raw records to a nonsensical 118 "matched pairs") — caused by joining WT and mutant records on `(molecule_chembl_id, standard_type)` without first collapsing repeat measurements per compound, creating a cross-product of every WT row against every mutant row for the same compound. Fixed by taking the median per-compound value on each side before joining, so a "matched pair" is genuinely one compound tested in both conditions.
5. A reference bug (`mut_df` vs `all_mut_df`) in the final assembly cell — cosmetic, fixed on the next paste.

**Major real finding — EGFR's resistance mutations are overwhelmingly compound, not independent single mutations.** Direct ChEMBL query showed L858R+T790M (3,402 records) and L858R+T790M+C797S (971 records) vastly outnumber pure T790M-alone (1,361) or pure C797S-alone (33) — C797S essentially never occurs without T790M already present, exactly matching the clinical mechanism (each resistance mutation arises on top of the previous one). **This changed the actual analysis design**, not just the framing: rebuilt as a three-step cascade (WT→L858R→L858R+T790M→L858R+T790M+C797S) with T790M scored against an L858R background and C797S scored against an L858R+T790M background (not the T790M-only background originally built) — background-aware scoring turned out to be the dominant real-world case for EGFR, not a special-case nicety. ABL1 checked for the same pattern and found clean (zero compound mutations across 8,516 variant-annotated records) — original single-mutation-vs-WT design stands for ABL1.

**Panel expanded mid-session after the initial 13-mutation panel proved underpowered** (see below) — added 3 more EGFR driver mutations (L861Q, G719C, G719S — confirmed via literature search as legitimate "uncommon activating" EGFR mutations, same category as L858R) and 4 more ABL1 resistance mutations (F317L/I — confirmed dasatinib-resistance, 9-13.5x IC50 shift in cellular assays; H396P, Q252H — confirmed imatinib-resistance mutations via case-report literature). Final panel: 6 EGFR mutations/steps, 13 ABL1 mutations (9 reliable after filtering).

**Matched-pair construction — primary vs. secondary tiers, as required by the earlier critique.** For each mutation, WT and mutant ChEMBL records were matched by `(molecule_chembl_id, standard_type)` after per-compound median collapse, giving a true one-row-per-compound matched set (the controlled ΔpIC50 benchmark). ## 7c. External review + critical fix: ChEMBL "matched pairs" were compound-matched, not assay-matched (this session)

**The critique (from an external reviewer pass on the draft manuscript):** the existing matched-pair construction grouped WT and mutant ChEMBL records by `(molecule_chembl_id, standard_type)` only — same compound, same assay type — then took the median on each side. This does not control for assay format, publication, lab, or protocol. A single compound-target pair can show IC50 values spanning >100x across different papers purely from assay-heterogeneity (biochemical vs. cell-based, different ATP concentrations, etc.), even within the *same* document. Calling the result a "matched pair" overstated what was actually controlled for. **This critique is correct and was the single highest-priority fix identified.**

**Concrete evidence found while fixing it:** compound CHEMBL68920 vs EGFR WT, within a single document (CHEMBL1134862), shows IC50 = 41, 300, and 7820 nM across three different assay formats (`BAO_0000357` vs `BAO_0000219`) — a 190x spread from assay-format alone. Worth quoting directly in the manuscript's limitations section as concrete, not theoretical, evidence.

**Fix implemented:** added `document_chembl_id` (same publication) and `bao_format` (same assay format) as required matching keys, on top of `(molecule_chembl_id, standard_type)`. Checked whether an even stricter same-`assay_chembl_id` tier exists (i.e., one assay entry testing both WT and mutant directly) — confirmed it does not (0 such cases found across the panel), because ChEMBL assay entries are curated per target-variant, not per head-to-head comparison. Document-level matching is therefore the strictest tier the data actually supports. Two-stage aggregation used: median per compound (collapsing that compound's own multiple document-matches first), then median across compounds — so no single heavily-studied compound (some had 5+ independent document-matches) dominates a mutation's score.

**Result: the reliable mutation set barely changed in size (still 9/13 ABL1, 6/6 EGFR = 15/19 combined reliable), but the Δp values themselves changed substantially for several mutations** — direct evidence the original compound-pooled numbers were meaningfully distorted by assay heterogeneity, not just theoretically vulnerable to it:

**Paired model comparison for EGFR/ABL1 (completed this session).** MET's per-drug Wilcoxon pairing doesn't transfer directly — EGFR/ABL1 mutations aren't tested against a fixed, shared compound panel the way MET's variants are tested against the same 9 drugs, so there's no natural "paired by drug" structure. **Window/flank sensitivity analysis (completed this session).** Two-part check on a 17-mutation non-cascade subset (excludes T790M/C797S, which score against a mutant background rather than WT — out of scope for this particular check, stated explicitly rather than silently narrowed):

1. **Full-length vs. windowed ESM-2-150M** (the stronger test — ESM-2 has no 1024-token cap, so it can be scored on the true full-length EGFR/ABL1 sequence and compared directly against the windowed scores used everywhere else in the pipeline): Spearman ρ=0.998, Pearson r=0.999, mean absolute score difference 0.155 against a ~13-unit score range. Windowing introduces no meaningful distortion for this model.
2. **ESM-1b at alternate flank sizes** (100 and 250 residues, vs. the original 150 — ESM-1b can't be scored full-length due to the hard cap, so this tests stability across reasonable window-boundary choices instead): flank=100 vs. original, ρ=0.934; flank=250 vs. original, ρ=0.966. Both strong. **Conclusion for the manuscript:** window/flank choice does not materially affect zero-shot scores or the rankings/correlations built on them, for either model family, across the range of reasonable choices tested. This closes the sensitivity-analysis item cleanly and positively.
